# 🩸 Cadastro de Doadores de Sangue

MVP acadêmico de um sistema web para gerenciamento de cadastros de doadores de sangue.

O sistema permite que um administrador autenticado cadastre, consulte, pesquise, edite e exclua doadores.

## 🚀 Tecnologias utilizadas

- Python
- Flask
- MySQL
- HTML
- CSS
- Git e GitHub

## ✅ Funcionalidades

- Login do administrador
- Cadastro de novos doadores
- Listagem dos doadores cadastrados
- Consulta dos dados de um doador
- Edição de cadastros
- Exclusão de cadastros
- Pesquisa por nome
- Filtro por tipo sanguíneo
- Filtro por cidade
- Validação dos campos obrigatórios
- Registro do consentimento para tratamento dos dados
